## Project Overview

Podil is a Rails 8 music search application that aggregates data from multiple music APIs (YouTube, Last.fm, Genius) to provide users with song information and purchase/streaming links. The app uses a modern Rails stack with Hotwire (Turbo + Stimulus), Tailwind CSS, and esbuild.

## Development Commands

### Setup
```bash
bundle install
npm install  # or yarn install
bin/rails db:setup
```

### Running the App
```bash
bin/dev  # Starts web server, JS bundler, and CSS watcher via Procfile.dev
```

Individual processes:
- `bin/rails server` - Rails server
- `yarn build --watch` - JavaScript bundler (esbuild)
- `bin/rails tailwindcss:watch` - Tailwind CSS watcher

### Testing
```bash
bin/rails test              # Run all tests
bin/rails test:system       # Run system tests only
bin/rails db:test:prepare   # Prepare test database
```

Single test file:
```bash
bin/rails test test/controllers/search_controller_test.rb
```

### Code Quality
```bash
bin/rubocop           # Run linter
bin/rubocop -a        # Auto-correct linting issues
bin/brakeman          # Security vulnerability scanning
```

### Database
```bash
bin/rails db:migrate        # Run migrations
bin/rails db:rollback       # Rollback last migration
bin/rails db:reset          # Drop, create, migrate, seed
```

### Asset Building
```bash
npm run build       # Build JavaScript (esbuild)
npm run build:css   # Build Tailwind CSS
```

## Architecture

### Service Layer Pattern

The app uses Service Objects to encapsulate external API interactions:

- **GeniusService** (`app/services/genius_service.rb`): Genius API for lyrics and song metadata
  - Requires `GENIUS_ACCESS_TOKEN` environment variable

- **LastfmService** (`app/services/lastfm_service.rb`): Last.fm API for track information
  - Requires `LASTFM_API_KEY` environment variable

- **YoutubeService** (`app/services/youtube_service.rb`): YouTube API for video search
  - Requires `YOUTUBE_API_KEY` environment variable

All services use HTTParty for HTTP requests.

### Request Flow

1. User submits search query via `SearchController#index`
2. `SearchController#results` orchestrates API calls:
   - Queries YouTube API for video results
   - Uses YouTube metadata to query Last.fm for track info
   - Builds purchase/streaming links for multiple platforms
3. Returns results with embedded video player and platform links

### Frontend Stack

- **Hotwire**: Turbo Drive for SPA-like navigation, Stimulus for JavaScript sprinkles
- **Tailwind CSS**: Utility-first CSS with plugins (@tailwindcss/forms, @tailwindcss/typography, @tailwindcss/aspect-ratio)
- **esbuild**: Fast JavaScript bundling
- **Asset Pipeline**: Propshaft for static asset serving

### Database Configuration

- Development/Test: SQLite3
- Production: PostgreSQL (configured via `DATABASE_URL`)
- Solid Queue: Database-backed job queue
- Solid Cache: Database-backed caching
- Solid Cable: Database-backed Action Cable

## Environment Variables

Required for full functionality:
```
GENIUS_ACCESS_TOKEN=<your-genius-token>
LASTFM_API_KEY=<your-lastfm-key>
YOUTUBE_API_KEY=<your-youtube-key>
RAILS_MASTER_KEY=<auto-generated>
```

Store in `.env` file (excluded from git via `.gitignore`).

## Deployment

Uses Kamal 2.8+ for containerized deployment:

```bash
bin/kamal deploy        # Full deployment
bin/kamal console       # Rails console on production
bin/kamal logs          # Tail production logs
bin/kamal shell         # SSH into container
```

Configuration: `config/deploy.yml`

## Code Style

- Follows Rails Omakase Ruby styling via `rubocop-rails-omakase`
- Configuration: `.rubocop.yml`
- CI enforces linting via GitHub Actions

## CI/CD

GitHub Actions workflow (`.github/workflows/ci.yml`) runs on PRs and pushes to main:
1. Brakeman security scanning
2. RuboCop linting
3. Full test suite with PostgreSQL service
4. System tests with Chrome/Selenium
